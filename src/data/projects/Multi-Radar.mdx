## Overview

This project involved the development of a synchronized multi-radar millimeter-wave tracking system for real-time, privacy-preserving human monitoring in healthcare environments.

Five 60 GHz FMCW radar modules were arranged in a semicircular configuration around a 3D-printed modified GRIN Luneburg lens to achieve continuous 140° angular coverage. The system was experimentally validated in a clinical research environment and demonstrated reliable multi-zone tracking and fall detection.

While the dielectric lens design was led by other members of the team, my work focused on the radar configuration, signal processing pipeline, multi-process backend architecture, synchronization, GUI development, and fall-detection logic.

---

## System Architecture

### Hardware Configuration

The system consists of:

- 5× Infineon BGT60TR13C FMCW radar modules (58–63 GHz)
- 3D-printed 10 cm modified GRIN Luneburg lens
- Semicircular radar placement (~28° spacing)
- Centralized Python control system

The integrated lens increased realized gain by approximately 12 dB per radar, corresponding to roughly a 4× detection range improvement compared to standalone radar modules.

## Radar & Signal Processing

Each radar operated in 1TX / 1RX mode to prioritize reliable amplitude-based detection at short range.

**Operating parameters included:**

- 58–63 GHz frequency sweep  
- 16 chirps per frame  
- 128 samples per chirp  
- 50 ms frame repetition  

Each radar was independently baseline-calibrated using frame averaging, followed by adaptive thresholding (~0.75 dB above baseline). Detections were fused into a unified occupancy model across five spatial zones.

## Multi-Radar Synchronization

To support five radars operating simultaneously, I implemented a multiprocessing architecture in Python:

- One independent process per radar  
- Shared memory queue for data exchange  
- Central fusion logic layer  
- JSON-based messaging for GUI updates  

This architecture ensured:

- True parallel acquisition  
- Minimal latency  
- Consistent temporal alignment  
- Smooth zone-to-zone handoff

## Fall Detection Logic

The fall-detection system followed a structured state-machine approach:

1. Initial presence detection  
2. Signal persistence verification  
3. Disappearance timer (10–20 seconds depending on zone)  
4. Reappearance check or alert trigger  

If no signal reappeared within the timeout window, the system transitioned to an alert state and triggered a GUI warning.

This reduced false alarms while maintaining sensitivity to real fall events.
